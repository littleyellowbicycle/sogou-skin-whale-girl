## 边框：统一改成单线

参考截图的边框是**一圈线**。之前我做成了「外线 + 内侧细线」两圈，观感偏重、也不像。现在四套统一：

- 只保留一条 1.5~1.6px 的描边
- 羊皮卷主题额外带**圆角卷饰**：从边框线上「勾」进纸面的卷须 + 一颗小圆点（不是另画一条平行线——那样放大看会像多余毛刺）

## 三套共用的设计

- **鲸鱼喷水挂件**：候选框左侧一只小鲸鱼剪影 + 往上喷的水花（含一颗腮红粉水滴）。挂件放左下角，一次满足「水花尾巴 + 迷你鲸鱼」两个想法。
- **角落气泡**：透明度 18% / 13% / 10%，不抢文字。
- **圆角 14px**（Q 版二头身比例）。
- **按键三态**：常态 / 悬停 / 按下各一张图；浅色方案按键带一道「深半度」描边，避免在白色文档里糊成一片。
- **无悬停态的候选框**：格式限制，选中项只能靠文字变色，所以三套都把明度阶梯拉开了（首选最深 / 其它中间 / 拼音最浅）。

## 四个动作（三套都有）

状态栏 18 帧循环：**待机 3 → 吃白饭 8 → 待机 2 → 敲键盘 5**，150ms/帧 ≈ 2.7 秒。

## 怎么改

配色集中在 `work/spec_v2.py` 的 `THEMES` 字典，一套主题一段：

```python
"night": {
    "body_top": "#1B2A4A", "body_bot": "#131F38", "body_alpha": 0.88,
    "border": "#486090", "inner": "#4FC3F7", ...
}
```

改完按主题重跑（环境变量切换）：

```powershell
$py = "C:\Users\10215\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
cd sogou-skin\work
foreach ($t in "foam","night","cream") {
    $env:SKIN_THEME = $t
    & $py render_v2.py; & $py build_v2.py; & $py preview_v2.py
}
$env:SKIN_THEME = "foam"; & $py compare.py    # 重新出对比图
```

| 想改什么 | 改哪里 |
| --- | --- |
| 三套配色 / 透明度 / 高光强度 | `spec_v2.py` 的 `THEMES` |
| 气泡透明度、圆角 | `spec_v2.py` 的 `BUBBLE_OPACITY`、`RADIUS` |
| 挂件大小位置 | `render_v2.py` 的 `whale_ornament(x, y, s)` 调用 |
| 动作编排 / 节奏 | `spec_v2.py` 的 `SEGMENT_PLAN`、`FRAME_MS` |
| 横排文字左缩进（挂件占位） | `SCHEMES["H1"]["pinyin_marge"][2]` |

### 两套浅色的「选中高亮」为什么必须替换（已确认采用方案 A）

实测对比度：

| 规格色 | 压在底色上 | 对比度 |
| --- | --- | --- |
| 泡沫 选中高亮 #A8C8E8 | #F6FAFE | **1.66 : 1** |
| 奶油 选中高亮 #F7C9C0 | #FFF9F4 | **1.43 : 1** |
| 夜航 选中高亮 #4FC3F7 | #1B2A4A | 7.10 : 1 |

1.4~1.7:1 等于字看不见。这两个高亮色原本是为**选中项背景块**设计的，而搜狗皮肤格式只能给文字上色，没有背景块。

处理方式（**方案 A，用户已确认**）：

- #A8C8E8 / #F7C9C0 用作**装饰色**（气泡、水花），这两处它们很好看；
- 选中态由**明度**承担：首选最深、其它次之；
- 泡沫的「候选文字」因此拆两档：首选 #304878、其它 #55709A（全用一个色就没有选中概念）。

被否决的方案 B：严格照抄 hex，让首选词直接等于高亮色——字面上 4 个色全对上，但选中的候选在浅底上基本不可见。
